\section{Problem Statement \& System Engineering Constraints}

\subsection{Formal Problem Definition}

State the engineering problem clearly and specifically.

The problem should identify:
\begin{enumerate}
    \item the existing limitation,
    \item the consequence of that limitation,
    \item the affected users/system components,
    \item and the engineering need being addressed.
\end{enumerate}

\subsection{System Constraints Analysis}

regulatory, safety, and timing constraints.
